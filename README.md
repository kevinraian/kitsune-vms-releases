# Kitsune VMS — Downloads

Central de monitoramento de câmeras para Windows (RTSP, ONVIF e webcams), com PTZ, detecção de movimento e reconhecimento de objetos por IA local.

**Baixe o `KitsuneVMS-win-Setup.exe` na página de [Releases](../../releases/latest).** O app se atualiza sozinho (Configurações → Sobre).

> O aplicativo ainda não é assinado digitalmente. O SmartScreen pode avisar: clique em *Mais informações → Executar assim mesmo*. Com o Smart App Control ativo, o Windows bloqueia o programa.
